# Backdrop images

`rune-slate.webp` (34 KB) was made on 24 Oct 2026 for Jakob Lomander Boman, in a Claude Code cloud session, with Stable
Diffusion XL base 1.0 (`stabilityai/stable-diffusion-xl-base-1.0`, CreativeML Open RAIL++-M) on the CPU, using
`tools/tile-art/backdrop.py --cpu` (seed 7302, chosen from 7301–7304: DPM++ 2M Karras, 30 steps, cfg 7, 768×1344, the
prompt and negative prompt in the script), then finished with `backdrop.py --finish` (720 px wide, colour 0.55,
brightness 0.42, WebP quality 60). To the extent possible under law, it is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

It replaces the first trial (seed 7101, made on the owner's local ComfyUI), which had faux-text blocks near the top and
bottom.
