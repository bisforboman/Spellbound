# Backdrop images

`rune-slate.webp` (27 KB) was made by Jakob Lomander Boman on 24 Oct 2026 with Stable Diffusion XL base 1.0
(`sd_xl_base_1.0.safetensors`) in a local ComfyUI, using `tools/tile-art/backdrop.py` (candidate `backdrop-7101-1`,
seed 7101), then finished with `backdrop.py --finish` (720 px wide, colour 0.55, brightness 0.42, WebP quality 60).
To the extent possible under law, it is dedicated to the public domain under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

It is a trial: it has faux-text blocks near the top and bottom, which a re-roll (another seed) or a centre crop would
remove if the rune-slate look is kept.
