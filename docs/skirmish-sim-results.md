# Skirmish simulation results

Generated by `tools/Spellbound.SkirmishSim` with the default `SkirmishRules`; don't edit by hand. Each scenario is 1000 games of 4 seats, seeds 7–1006, with the seats rotated every game (so each bot plays every school and every start).

## Bots

- **Expander:** claims every region it can reach (richest terrain first) and builds towns; when nothing is free, recruits and attacks sure wins
- **Builder:** one claim a round, its school's self-spell whenever none is running, then towns (a node every few rounds) and defenders
- **Fighter:** recruits Unit 3 every round, attacks regions it surely wins, claims with what's left
- **Hexer:** hexes the leader every round, keeps a ward up, claims and builds nodes
- **Quitter:** plays like the Expander for 4 rounds, then never readies up again
