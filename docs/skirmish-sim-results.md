# Skirmish simulation results

Generated by `tools/Spellbound.SkirmishSim` with the default `SkirmishRules`; don't edit by hand. 1000 games of 4 seats, seeds 7–1006, seats rotated every game. Part A rules: claims, builds, recruits and the discovery deck; no attacks, hexes or spells yet, so mana and armies only matter for contested claims.

## Bots

- **Expander:** claims every region it can reach (richest terrain first), then builds towns
- **Builder:** one claim a round, then fills its regions with towns (and a node every few rounds)
- **Fighter:** recruits Unit 3 every round to win contested claims, then claims two regions
- **Half-present:** plays like the Expander, but misses every other round
